# LoreRim Alchemy Book

A browser-based alchemy companion for LoreRim 5.0.

## Features

- Build potions by selecting ingredients with shared effects
- Save potions to a local Potion Database
- Search and filter saved potions
- Favorite, delete, import, and export potion recipes
- Look up ingredients and their effects
- Search effects to find matching ingredients
- Calculate Witcher consumable values based on relevant perks
- Track Witcher ingredients
- Generate an Ingredients to Collect list from saved potions and tracked Witcher ingredients
- Works on desktop and mobile

## Version

Current release: v1.0.0  
Built for: LoreRim 5.0
